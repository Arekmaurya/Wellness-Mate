📌 Problem Statement

😰

The Mental Health Gap

Over 150 million Indians need mental health support, but fewer than 1 in 10 receive adequate care due to stigma and lack of access.

🤖

AI as a Bridge

Generic chatbots lack the empathy and clinical understanding needed for mental health conversations. A domain-specific fine-tuned model can fill this gap.

Source: WHO, NIMHANS Reports

🎯 Objectives

  • Fine-tune a domain-specific LLM on psychiatric counseling data
  • Build an accessible, privacy-first wellness chatbot (runs locally via Ollama)
  • Provide features beyond chat: affirmations and guided meditation
  • Containerize with Docker for one-command deployment
  • Deploy on Hugging Face Spaces and Docker Hub for public access

✨ Key Features

💬

AI Chat

Empathetic conversations with a fine-tuned psychiatrist model. Maintains context across messages with sliding window.

🌞

Positive Affirmations

On-demand motivational affirmations tailored for stress relief and mental wellness.

🧘

Guided Meditation

AI-generated 5-minute calming meditation scripts with soothing language.

🔒 Privacy-First Design

Everything runs locally via Ollama — zero data leaves the user's machine. No cloud API calls, no logging of conversations.

🔐 Security & Code Quality

✅ Security Measures

• XSS Protection — All user inputs sanitized via html.escape() before rendering

• No External APIs — LLM runs locally, no data exfiltration risk

• Error Handling — All Ollama calls wrapped in try/except with graceful fallbacks

✅ Code Practices

• Modular Functions — Separate functions for chat, affirmation, meditation

• Session Management — Streamlit session state for conversation persistence

• Fallback Assets — Online background image if local file fails to load
